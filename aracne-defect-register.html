Checked and found sound

Places the audit went looking and came back with nothing.

SQLite locking

Every entrance goes through withSQLiteRead/Write; per-path RWMutex, busy_timeout set twice, retry on SQLITE_BUSY, migrations under sync.Once. The DSN parameter names match modernc’s reader.

Batch edit atomicity

applyBatch resolves every hunk in memory before touching disk, locks paths in sorted order (no ABBA), and writes through AtomicWriteFile. CRLF is matched on the strings, not the file.

Shell parser conservatism

shellcmd returns KindPassthrough for every flag it does not model, including -c, -f, -o, negative counts and zero counts. BRE→RE2 rewriting refuses backreferences and collating classes.

Terminal raw mode

tui.Open installs the signal handler before entering the alternate screen and restores through a sync.Once reachable from both the defer and the handler.

Viz origin gate

Host must resolve to loopback and any browser-supplied Origin must be loopback too, so DNS rebinding is closed for the whole /api/ surface.

MCP protocol edges

Request ids are echoed as raw JSON (string ids work), absent arguments normalises to {}, notifications get no response, and ping is answered.

Method

What was read, what was run, and what this audit did not cover.

What was read

Every non-test Go file under internal/ and cmd/ — about 112k lines including tests — with full reads of the files that carry the most behaviour: topology/manager.go, helper/{db,config,incremental,manifest,apply,sqlite}.go, cli/{guard*,cmd,setup,native_hooks}.go, shellcmd, topogrep, universaltools, readunit, renderstate, mcp, lazydesc, and the chat permission policy. Scanners were sampled rather than read line by line.

What was run

  • go vet ./..., go build ./..., go build -tags minimal ./..., go test ./... — all clean.
  • Four throwaway probe suites compiled against the packages under test, since the shipped suite covers none of these paths. They were deleted afterwards; the tree is unmodified.
  • The built arac binary against this repository’s own .aracne/topology.db: read, grep, cmd, scan, viz serve, and the guard --claude-hook PreToolUse path fed a synthetic event on stdin.
  • Direct SQLite queries against .aracne/topology.db for the stored error: rows and the colliding dependency nodes.

What this did not cover

  • The tree-sitter grammars themselves, and the per-language resolvers for Rust, Java, JS/TS and Python beyond spot checks. Those are where the remaining correctness surface is, and they need a corpus rather than a read.
  • The bench/ harness (Python, not in any build) and testing_ground/, which is deliberately edge-case corpus and deliberately not gofmt-clean.
  • The embedded SPA under internal/viz/static/.
  • Concurrency under real load. The races noted below are read from the code, not observed under contention.

A note on severity

Severity here is about what the fault does to a user of aracne, not about how deep in the stack it sits. A defect that quietly rewrites a file someone owns outranks one that returns a wrong graph edge, because the second is recoverable by rescanning and the first is not recoverable at all.
